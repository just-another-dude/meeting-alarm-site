Privacy policy

This policy covers meeting-alarm, a personal desktop tool that rings before Google Calendar meetings.

Data it accesses

With the user's permission, meeting-alarm reads Google Calendar events through the read-only scope https://www.googleapis.com/auth/calendar.readonly. It uses an event's title, description, start time, type, status and the user's own response status to decide whether to ring and what to show in the alarm.

Where data goes

Calendar data is processed on the user's own computer and kept in memory only while the program runs. The sign-in token is stored in a file on that computer. meeting-alarm has no server, and it does not send, sell or share calendar data with anyone.

Removing access

Access can be revoked at any time in the Google Account settings under Security, Third-party apps and services. Deleting the token file on the computer removes the stored sign-in.

Google API Services User Data Policy

meeting-alarm's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
